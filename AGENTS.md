# Призма

Мобильная игра-раскладка: дилемма → потребности раскладываются по вариантам → линзы (чувства/ценности) → сводка.
React 19 + Vite, без стейт-менеджеров и UI-китов, Telegram WebApp (`tg.ts`).

## Вайб (принципы, не стили)

- **Тактильность.** Всё перекладывается руками: drag с «поднятием» (клон над пальцем), подсветка зон, haptic при дропе. Не клик-интерфейс — интерфейс-стол.
- **DIY / sketchy.** Карандашная тетрадь в точечку: графитовая обводка (`--ink: #3a3428`), «дрожащий» радиус `--wob`, штриховка `--hatch` поверх цвета группы, зерно `body::after`. Шрифты: Caveat (от руки — подписи/хинты), JetBrains Mono (контролы), Unbounded (дисплей).
- **Плёнка + около-3D ортогонально.** Бумага тёплая (`--paper`), точечная фактура фона (`body::before` dot grid), лист лежит под наклоном `-0.6deg`. Не настоящий 3D и не движки — плоская сценка «предметы на столе», как стоп-кадр плёночного фото.
- **Life is Strange:** вещи на столе, а не UI-виджеты; тепло и рукодельность важнее плотности информации.

## Правила, которые уже раз обжигали

- Текст **не внутри** `clip-path`-фигур — обрезается. Подпись рядом/снизу (`.tri-word`, `.tlabel`).
- Цвет пирамидки = цвет её группы ННО: инлайним `--h: needHue(word)`, заливка (`--hatch` + градиент) в CSS.
- Свайп-колоды нет — стол `.board` + лист `.paper` + сгиб `.fold` (= обоим).
- На перетаскиваемом элементе `touch-action: none`, на фоне — `pan-y` (иначе жест съедает скролл или наоборот). Зона захвата = строго видимый треугольник: обработчики на `.ttri`/`.ltri`, `clip-path` режет и хит-зону; никаких невидимых полей вокруг (`.thit` пробовали — мешает скроллу). Подпись `.tlabel` и войлок — скролл.
- В Telegram обязателен `disableVerticalSwipes()` в `initTg` (Bot API 7.10+): без него вертикальный свайп сворачивает мини-апп поверх драга. Плюс `overscroll-behavior` на `.board`/body — жест не пробрасывается в нативный контейнер.
- `prefers-reduced-motion` уже глушит анимации — не ломать.
